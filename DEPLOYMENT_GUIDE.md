## 🚀 Quick Deployment

### 1. System Requirements Check
```bash
# Verify Python version (3.8+ required)
python3 --version

# Check available memory (4GB+ recommended)
free -h

# Verify disk space (10GB+ recommended)
df -h
```

### 2. Install Dependencies
```bash
# Install system dependencies (Linux)
sudo apt-get update
sudo apt-get install -y nmap tor proxychains dnsutils whois build-essential

# Install Python dependencies
pip install -r requirements.txt

# Or run automated installer
python3 install.py
```

### 3. Launch APTS
```bash
# Start the system
python3 apts.py

# Follow the setup wizard
# 1. Confirm authorization
# 2. Activate Ghost Mode
# 3. Configure targets
# 4. Run assessment
```
